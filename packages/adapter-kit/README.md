# @noeos/verifactu-adapter-kit

Kit ejecutable de conformance para adapters de persistencia VERI*FACTU. Comprueba commit/duplicado
de `RecordStore` y fencing de leases de `OutboxStore` sin acceder a SQL, disco, red o secretos.

Kit de conformidad para comprobar implementaciones de los puertos públicos de Noeos VERI*FACTU. No sustituye una revisión del host ni constituye certificación legal.
