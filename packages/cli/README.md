# @noeos/verifactu-cli

CLI pública de Noeos VERI*FACTU (versión de desarrollo). Lee JSON/NDJSON con límites explícitos y
produce salidas `human`, `json` o `ndjson`. Las operaciones de capacidades, fuentes, vectores,
aplicabilidad, huella, QR e inspección de respuestas son reproducibles; las operaciones que exigen
persistencia, firma, certificados o red requieren adapters proporcionados por el host.
