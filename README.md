# VeriFactu

VeriFactu is currently a documentation-only project. The approved documents in
[`docs/`](docs/) specify a future Spanish RRSIF/VERI*FACTU component; they do
not constitute a product implementation, regulatory edition, package, release,
or compliance claim.

The canonical execution plan is
[`docs/17-roadmap-risk/implementation-roadmap.md`](docs/17-roadmap-risk/implementation-roadmap.md).
All repository changes use the single-maintainer protected flow described in
[`CONTRIBUTING.md`](CONTRIBUTING.md).

No product source exists in this repository at the P1 baseline.
