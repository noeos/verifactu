# Noeos VERI*FACTU

Componente público y reutilizable de Noeos para implementar los modelos, validaciones y procesos de VERI*FACTU (RRSIF). Lo integrará la aplicación comercial de facturación.

Este repositorio concentra las reglas regulatorias y su trazabilidad. La facturación conserva la gestión comercial y de documentos, mientras que [Verification Engine](https://github.com/noeos/verification-engine) aporta funciones genéricas de integridad sin lógica fiscal.

## Estado

Repositorio inicial. La especificación y el desarrollo se incorporarán aquí conforme se definan los contratos y flujos del componente.
