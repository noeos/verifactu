# Security policy

No supported product version exists yet. Do not include taxpayer data, invoice
data, certificates, private keys, tokens, or other secrets in a public issue.

Report suspected vulnerabilities through GitHub private vulnerability reporting
for `noeos/verifactu`. If that channel is unavailable, contact the repository
owner through the contact published by the Noeos GitHub organization. Public
discussion should contain only sanitized reproduction details.

Security reports will be acknowledged and assessed, but no response-time or
remediation-time guarantee is claimed before a support policy is published.
