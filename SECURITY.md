# Security Policy

## Supported versions

No production version has been released. Supported release lines and end dates will be published before 1.0.0.

## Reporting

Report vulnerabilities privately through GitHub Private Vulnerability Reporting. Do not open a public issue for an undisclosed vulnerability.

Never include real invoices, tax identifiers, XML payloads, private keys, PINs, access tokens or production certificates. Use a minimal synthetic reproduction and affected version.

Security handling and incident policy are defined in [`docs/08-seguridad/06-vulnerabilidades-incidentes.md`](docs/08-seguridad/06-vulnerabilidades-incidentes.md).
