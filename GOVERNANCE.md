# Governance

The approved normative corpus in `docs/` governs this repository. [`docs/00-gobierno/01-autoridad-documental.md`](docs/00-gobierno/01-autoridad-documental.md) controls precedence and conflicts; this file cannot override it.

## Initial ownership

`@ddavid07` is the initial product, regulatory, security, release, privacy and documentation owner. Additional maintainers must have explicit scope and recovery material before receiving privileges.

## Decisions

- Approved behavior changes only through a decision that records sources, requirements, compatibility, migration, security, performance and evidence.
- Chat, comments and untracked notes are not decision records.
- Contradictions and unknown regulatory drift block affected implementation and release.
- Lack of an independent reviewer is disclosed; no review is simulated.

## Enforcement

Rulesets, CODEOWNERS, DCO, signed commits/tags, required CI, protected release environments, source manifests and release verification enforce this model.
