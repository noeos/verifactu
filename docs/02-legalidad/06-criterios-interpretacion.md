# Criterios de interpretación

Estado: **normativo**

## Método

1. Determinar texto y fecha aplicables.
2. Identificar sujeto, acción, momento, datos y excepción.
3. Contrastar reglamento, orden y especificación habilitada.
4. Consultar FAQ y ejemplos para casos, sin elevar su rango.
5. Formular una regla determinista o declarar la ambigüedad.
6. Registrar alternativas, riesgo y prueba discriminante.

## Reglas de seguridad jurídica

- Una obligación no se elimina por silencio de un documento inferior.
- Un ejemplo no amplía el conjunto válido si contradice un esquema superior.
- El comportamiento más permisivo no es el default.
- Fechas, zonas horarias, redondeos y valores vacíos se resuelven con fuente; nunca por costumbre del lenguaje.
- Las traducciones son informativas salvo autoridad equivalente.
- La compatibilidad histórica conserva la interpretación con la que se creó la evidencia.

Las ambigüedades abiertas se representan como riesgos bloqueantes, no como comentarios en código.
