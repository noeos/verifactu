# Requisitos no funcionales

Estado: **normativo**

- **Corrección:** los bytes y estados oficiales son reproducibles y verificables.
- **Seguridad:** fallo cerrado, mínimo privilegio y ninguna omisión silenciosa.
- **Trazabilidad:** toda decisión enlaza fuente, requisito, contrato, prueba y release.
- **Compatibilidad:** versiones históricas permanecen verificables.
- **Disponibilidad:** las caídas externas se absorben mediante colas durables sin perder orden ni identidad.
- **Operabilidad:** diagnósticos accionables sin exponer datos fiscales.
- **Portabilidad:** Node.js soportado en Linux, Windows y macOS; cifras oficiales en Linux x64.
- **Rendimiento:** memoria acotada, streaming y gates absolutos y relativos.
- **Privacidad:** minimización, redacción y ausencia de telemetría por defecto.
- **Accesibilidad documental:** navegación, lenguaje claro y contratos legibles por máquinas.
- **Reproducibilidad:** build, contratos, vectores, paquetes y expediente se reproducen desde un commit.
- **Mantenibilidad:** módulos por responsabilidad, dependencias dirigidas y límites comprobados automáticamente.

No se acepta disponibilidad a costa de emitir, firmar o enviar un registro cuya corrección no pueda demostrarse.
