# Release 1.0.0 criteria

`1.0.0` requires both modes, all required records/events/validation/hash/XML/XSD/
XAdES/certificates/QR/AEAT states, atomic storage/outbox/recovery, public library/
CLI/kit, complete Engine/adapters and future-Facturacion host-contract conformance
through the maintained synthetic host, official/external evidence,
security/privacy/performance, three packages/supply chain, legal/CRA/declaration
handoff, support/runbooks/recovery and all audits/historical findings.

Every item links exact current evidence; zero material unknown, vulnerability,
risk, exception, drift or unowned requirement. Synthetic full release and account/
restore drills pass before production tag. “Works”, MVP or future implementation
is not a criterion.

The Facturacion application does not yet exist. Its real integration is therefore
not a VeriFactu `1.0.0` gate and MUST NOT be claimed. This release instead freezes
and proves the public host/UoW contract, adapter kit, synthetic lifecycle and
integration guidance that the future Facturacion repository will consume.
