# Definition of done

Done means reviewed implementation in correct boundaries; regenerated contracts;
positive/boundary/adversarial/recovery/performance tests; honest coverage/mutation;
security/privacy/supply-chain/compatibility; actual tarball consumer; documentation/
changelog/migration; and complete exact-head evidence through protected checks.

No related material finding, expired exception, unknown result or unsupported
claimed matrix cell remains. Mock/skip, local-only pass, green aggregate, merged
PR or rewritten status cannot substitute. Downstream graph and risks are updated.
