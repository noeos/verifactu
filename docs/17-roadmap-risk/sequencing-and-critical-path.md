# Sequencing and critical path

Critical sequence is governance/tooling → official editions → domain/formats →
atomic persistence → AEAT/public surfaces → assurance/performance → real
integrations/external validation → release/legal audit. Long-lead legal review,
certificates, npm namespace, performance runner, Facturacion fixture and external
AEAT access begin early without claiming completion.

Parallel work is allowed only for contract-frozen independent outputs. Buffers
protect regulatory/external uncertainty, not hide it. Recompute path on source,
scope, risk, dependency or failed evidence; calendar delay cannot reduce gates.
