# Autoridad documental

Estado: **normativo**

## Precedencia

1. Derecho vigente publicado oficialmente.
2. Especificaciones técnicas que la norma habilita expresamente a publicar a la AEAT.
3. Contratos públicos versionados de este repositorio.
4. Decisiones registradas.
5. Resto de documentación y ejemplos.

Código, pruebas, comentarios, incidencias y comunicaciones no pueden contradecir esta jerarquía. Una FAQ ayuda a interpretar, pero no modifica una norma superior. Un texto consolidado facilita la lectura; la publicación oficial original y sus modificaciones conservan el valor jurídico.

## Estados

- **Borrador**: discutible; no habilita implementación.
- **Revisado**: coherente, pero aún no vinculante.
- **Normativo**: aprobado y exigible.
- **Histórico**: preservado para verificar versiones anteriores.
- **Retirado**: no aplicable a trabajo nuevo; conserva sustituto y motivo.

## Cambios

Todo cambio normativo registra autor, fecha, motivación, fuentes, requisitos afectados, impacto de compatibilidad, pruebas exigidas y decisión. Los cambios de bytes, huella, firma, XML, estados o significado de errores crean una nueva edición regulatoria; nunca reescriben evidencia histórica.

## Contradicciones

Quien detecte una contradicción DEBE detener la parte afectada, abrir una decisión, clasificar el riesgo y marcar el resultado como indeterminado. Queda prohibido escoger silenciosamente la interpretación más conveniente.
