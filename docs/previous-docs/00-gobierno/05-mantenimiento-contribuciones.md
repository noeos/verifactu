# Mantenimiento y contribuciones

Estado: **normativo**

## Responsabilidades

- El propietario de Noeos aprueba alcance, decisiones de alto impacto y releases estables.
- El mantenedor regulatorio controla fuentes, interpretaciones y ediciones.
- El mantenedor técnico protege contratos, arquitectura, seguridad y calidad.
- Quien cambia una regla es responsable de actualizar trazabilidad, pruebas, documentación y expediente.

Una persona puede desempeñar varios roles, pero ninguna comprobación se simula. La ausencia de un revisor independiente se declara en la evidencia.

## Flujo

1. Incidencia o propuesta con requisito y fuente.
2. Rama con commits firmados y DCO.
3. Cambio atómico de documentación, contratos, pruebas y evidencia.
4. PR con impacto regulatorio, seguridad, compatibilidad y rendimiento.
5. Gates automáticos completos.
6. Resolución de conversaciones.
7. Squash firmado sobre `main`.

No se aceptan parches directos, excepciones permanentes, errores suprimidos ni comentarios que trasladen trabajo obligatorio a un futuro indefinido.
