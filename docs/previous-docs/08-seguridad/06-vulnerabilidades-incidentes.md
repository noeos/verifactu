# Vulnerabilidades e incidentes

Estado: **normativo**

Reporte privado mediante GitHub Private Vulnerability Reporting o canal publicado en `SECURITY.md`. No se solicitan datos fiscales, XML, certificados ni claves para reproducir.

## Severidad operativa

- crítica: triage inmediato, contención prioritaria y aviso coordinado;
- alta: triage en 24 h;
- media: 3 días laborables;
- baja: siguiente ciclo planificado.

El incidente conserva timeline, versiones, alcance, indicadores, decisiones, evidencias, parche, pruebas de regresión, publicación y lecciones. Un plazo de parche no se promete sin conocer impacto, pero una crítica no espera un ciclo ordinario.

Revocación de paquete, clave, certificado o edición tiene procedimiento separado. Comunicaciones públicas distinguen hecho confirmado, hipótesis e incertidumbre.
