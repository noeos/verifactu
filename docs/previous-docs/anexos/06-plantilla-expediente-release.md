# Plantilla de expediente de release

Estado: **normativo**

1. Identidad de producto, productor, versión, commit y tags.
2. Modalidades, ediciones, entornos y capacidades.
3. Fuentes oficiales con versiones/digests.
4. Matriz de requisitos e interpretaciones.
5. API, formatos, catálogos y compatibilidad.
6. Arquitectura e integración del SIF.
7. Threat model, controles, privacy y SBOM.
8. Resultados de tests, coverage, mutation, fuzz y performance.
9. Pruebas externas AEAT y respuestas saneadas.
10. Reproducibilidad, tarballs, checksums, firmas y attestations.
11. Recovery drill y operación.
12. Riesgos residuales, limitaciones y comprobaciones indeterminadas.
13. Declaración responsable aplicable o explicación de por qué el componente no es el SIF final.
14. Aprobaciones y timestamp.

Cada elemento incluye URI de artifact, digest y productor. El expediente es inmutable después de publicar.
