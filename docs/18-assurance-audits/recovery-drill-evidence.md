# Recovery drill evidence

Drill record names scenario, authorized isolated targets, starting subjects/
backup, injected failure, timeline/actions, measured RPO/RTO, restored digests/
chains/function, cleanup, deviations/findings and approval.

Required drills cover state/evidence restore, repo/build reconstruction, npm/
GitHub/key/account compromise, partial publish, nonreproducible build and
maintainer loss. Simulation is labelled; destructive production targets are
denied. Failed objectives block dependent release until correction/retest.
