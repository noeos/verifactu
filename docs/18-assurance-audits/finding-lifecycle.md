# Finding lifecycle

`FND-*` records source, affected subject/claim, reproduction/evidence, severity/
uncertainty, owner/SLA, root cause/related variants, treatment, regression,
verification and disclosure. States are new, triaged, active, mitigated,
verification-pending, closed, accepted-risk or reopened.

Closure requires current packaged evidence and effectiveness review; code/doc
change, alert dismissal or non-recurrence alone fails. Duplicate/superseded links
preserve history. Trigger/expiry/source change reopens automatically.
