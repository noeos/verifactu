# External verification plan

Before GA seek competent scoped review for Spanish tax/RRSIF/declaration and CRA/
privacy applicability, XML/XAdES/PKI interoperability, security assessment,
future-Facturacion host-contract/synthetic-fixture design and real available
adapter integration. Reviewer identity, independence/conflicts,
scope/method/date, exclusions, evidence and findings are retained.

External review cannot be fabricated or replaced by AI/tool output. Inaccessible
review remains blocker where required; otherwise public limitations identify the
unreviewed scope. Remediation and retest preserve original report.

Facturacion is not implemented at VeriFactu `1.0.0`; external review evaluates
integration readiness and boundary correctness, not a nonexistent real integration.
