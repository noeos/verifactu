# Control assurance mapping

Map source/requirement→threat/risk→control→implementation→positive/negative test→
job/report/evidence/release claim. Framework views cover applicable NIST SSDF,
SAMM, ASVS, OSPS, SLSA, SPDX/CycloneDX with exact version, rationale and gaps.

Mapping is not certification. Non-applicable needs product-boundary proof; partial
practice cannot satisfy a whole framework row. Generator rejects orphan controls,
missing falsification and stale evidence.
