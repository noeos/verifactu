# Supply-chain and release audit evidence

Audit admitted inputs, manifests/lock/install, clean builds/reproducibility,
tarball allowlists/consumers, licences/notices, dual SBOM reconciliation,
provenance/attestations, tag/OIDC/npm/GitHub identities and independent public
verification for all three packages.

Full populations/digests are required. Partial publication, cache trust, wrong
producer/subject and missing registry evidence have retained fault rehearsals.
Release is unsupported until every immutable external identity converges.
