# Postmortems and corrective action

Material incident, escaped defect, false-green gate, recovery miss or release
partiality gets a blameless timeline, impact/scope, detection/response, root and
contributing systemic causes, successful/failed controls, decisions, communications
and evidence. Restricted/public versions preserve privacy/embargo.

Actions have owner/deadline/risk/verification and address variants, not just
symptom. Effectiveness review and recurrence metric close them; publishing prose
does not. Lessons update requirements/ADRs/tests/runbooks without rewriting history.
