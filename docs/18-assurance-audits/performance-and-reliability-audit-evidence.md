# Performance and reliability audit evidence

Audit each budget/SLO against correct workload/data/adapter/build/qualified runner,
raw coordinated-omission-aware distributions, correctness/error/resource results,
baseline/noise and stress/soak/recovery. Self-hosted runner has no publication
secret and produces no executable release subject.

Wrong workload, warning-only breach, absent raw data or environment drift fails.
Claims name distribution/date/scope and exclude AEAT availability. Deviations link
risk/remediation and rerun evidence.
