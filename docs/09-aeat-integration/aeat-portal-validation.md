# AEAT portal validation

Portal exercises are authorized external observations, never ordinary PR CI.
Prerequisites are approved test taxpayer/representative and synthetic lawful
data, protected certificate handle, selected test environment/edition,
rate/schedule budget, source freshness, incident/contact plan and prohibition
on production effects.

The matrix covers each supported service/record/mode and representative success,
validation error, duplicate/correction, batch/partial, wait, consultation and
reconciliation path. Evidence retains exact release/package/configuration/
edition, request/response artifacts and digests, TLS safe metadata, timestamps,
CSV/official receipt and portal observations with secrets redacted.

Remote 5xx, timeout or undocumented response is a finding, not product failure
or success by itself. One accepted record cannot promote complete coverage.
Results expire on edition/endpoint/certificate/product changes and are kept
separate from deterministic release gates. Production smoke tests require a
later explicitly authorized non-destructive runbook.
