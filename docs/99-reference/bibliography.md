# Bibliography

This is generated from `REG-DOC-0004` and research records. Each entry preserves
publisher/authority, exact title/version, jurisdiction, publication/effective/
observed/review dates, canonical/final URI, media type, digest/signature/licence,
dependencies/supersession and claims using it.

Legal and exact-byte sources sort by authority then identity; engineering and
informative repository/forum sources remain visibly lower authority. Live URL
success is not pinning, and an unavailable source is never silently removed.
