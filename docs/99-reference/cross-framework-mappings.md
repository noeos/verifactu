# Cross-framework mappings

Generated maps relate applicable NIST SSDF/SP800-61/161, OWASP SAMM/ASVS, OSPS,
SLSA, SPDX, CycloneDX and product controls/evidence. Each row states framework
version/text, applicability rationale, implementation/control/test/evidence,
gap/residual risk and claim limitation.

Many-to-many mapping never means equivalence or certification. Partial/N/A/
unknown remains explicit and framework update triggers full semantic review.
