# Traceability index

Generated paths show source→requirement→decision/spec→implementation owner/path→
positive/falsifying test/oracle→task/job/report→commit/package/edition→release/
claim. Cardinality and evidence freshness are machine validated.

Views report orphan, missing, blocked, accepted-risk and demonstrated N/A without
converting links into satisfaction. Exact subject/environment/digest is visible;
old-code or previous-release evidence cannot close current work.
