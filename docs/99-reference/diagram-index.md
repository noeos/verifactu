# Diagram index

For every context/container/component/dynamic/state/data/deployment/threat/release
diagram, generate ID, viewpoint, owning normative model, source path, entities/
edges, renderer/version and last consistency result.

Diagrams are reviewable text and navigation only. Checker rejects unknown entity,
edge contradicting ownership/dependency/state, stale generation or parse failure.
Deleting a diagram cannot delete the normative rule it visualizes.
