# Identifier catalog

Generated from `GOV-008`, metadata and registries: family/pattern, canonical
object/path/title, authority/status/owner, introduced/superseded, inbound/outbound
links and release relevance. IDs are uppercase, immutable, unique and unrecycled.

Validation fails duplicate, malformed/unknown, missing canonical object, orphan
mandatory node, forbidden cycle or range not expanded for closure. Filename rename
does not change identity; this catalog cannot allocate IDs manually.
