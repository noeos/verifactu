# Release and support index

Generated table joins version/tag/source, three npm package/digests/dist-tags,
GitHub release/assets, edition/Engine/profile/runtime/OS/adapters, release state,
support start/end/level, dossier/declaration, advisories/deprecations and verifier.

Only independently verified published subjects appear as supported. Partial,
blocked, deprecated/EOL and historical-verification-only remain visible with
migration/replacement. `latest` live drift is an observation, never the canonical
version definition.
