# Package and product names

| Identity | Canonical name |
|---|---|
| Product/component | Noeos VeriFactu / `verifactu` repository |
| Library | `@noeos/verifactu` |
| CLI package / binary | `@noeos/verifactu-cli` / `noeos-verifactu` |
| Adapter kit | `@noeos/verifactu-adapter-kit` |
| Generic dependency | `@noeos/verification-engine` and its declared profile |
| Future host product | Facturacion, planned external repository/product boundary; not yet implemented or a VeriFactu `1.0.0` integration gate |

“AEAT certified/official”, “Facturacion engine” and Verification Engine as fiscal
oracle are prohibited aliases. Generated package/release metadata must match.
