# Glosario

Estado: **normativo**

| Término | Significado en este proyecto |
|---|---|
| AEAT | Agencia Estatal de Administración Tributaria. |
| Factura | Documento comercial y fiscal entregado al destinatario; no es el registro de facturación. |
| RRSIF | Reglamento aprobado por Real Decreto 1007/2023 y su desarrollo. |
| SIF | Sistema informático de facturación sujeto al RRSIF. |
| Registro de alta | Registro creado simultáneamente a la expedición de una factura. |
| Registro de anulación | Registro que deja constancia de la anulación; no borra el alta. |
| Registro de evento | Evidencia exigida sobre actuaciones relevantes, especialmente en NO VERI*FACTU. |
| VERI*FACTU | Modalidad con remisión continuada de registros a la AEAT. |
| NO VERI*FACTU | Modalidad legal de conservación en el sistema emisor, con controles adicionales. |
| Huella | Resultado del algoritmo oficial aplicado exactamente a los campos y representación definidos. |
| Encadenamiento | Inclusión de la huella del registro anterior conforme a la regla oficial. |
| Firma | Firma electrónica del registro cuando la modalidad y norma la exigen. |
| QR | Representación incluida en la factura conforme a los datos, tamaño y URL oficiales. |
| Edición regulatoria | Conjunto inmutable de fuentes, reglas, catálogos, formatos y vectores compatibles. |
| Expediente | Evidencias que justifican una versión y sus afirmaciones de conformidad. |
| Indeterminado | No existe evidencia suficiente para afirmar validez o invalidez. |
| Outbox | Registro transaccional de trabajo pendiente que evita perder una remisión tras confirmar datos. |
| Puerto | Contrato que el host implementa para proporcionar almacenamiento, firma, reloj o transporte. |
| Adaptador | Implementación concreta y sustituible de un puerto. |
| B2B | Facturación electrónica entre empresarios o profesionales; dominio relacionado pero fuera de alcance. |

Los nombres oficiales prevalecen sobre abreviaturas internas. Un término nuevo con efecto contractual se incorpora aquí antes de usarse como requisito.
