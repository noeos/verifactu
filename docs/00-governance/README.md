# Governance

This area defines how VeriFactu establishes authority, makes decisions, learns
from previous failures, controls change and proves that documentation is fit to
authorize implementation. It is the governance authority for every other
documentation area.

## Current status

The governance design was explicitly approved by the project owner on
2026-09-11. The governance documents and decision records are approved as the
design authority for the project. This approval concerns the documentation and
the intended controls; it is not evidence that the checker, negative fixtures,
CI workflows or GitHub protections already execute. Those operational controls
remain the first implementation work of P1.
