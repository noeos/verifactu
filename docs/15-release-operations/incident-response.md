# Incident response

NIST-aligned preparation, detection/analysis, response and recovery cover product
defect, fiscal integrity/data loss, privacy breach, dependency/build/runner,
GitHub/npm/domain/email/account/key/certificate, malicious package and regulatory
misstatement. One incident commander owns timeline and decisions.

Severity combines technical/exploitation/reachability with supported exposure,
RRSIF/CRA/GDPR/contract impact. Preserve evidence first, contain least
destructively, rotate/revoke affected authority, assess notification deadlines and
communicate confirmed fact/hypothesis/uncertainty distinctly.

Recovery uses verified clean subjects; monitoring and postmortem test corrective
effectiveness. Tabletop/technical drills exercise contacts, after-hours response,
partial publication and data breach without production destructive actions.
