# Contributing

This repository has one maintainer and uses a protected, zero-approval change
flow. That is an explicit governance model, not simulated independent review.

Before contributing:

1. Open or reference a bounded issue or approved work item.
2. Branch from current `main` using `<type>/<work-id>-<short-scope>`.
3. Make every human commit with `git commit -S -s`.
4. Keep the change coherent and update affected documentation and evidence.
5. Open a pull request using the repository template.
6. Wait for every required check on the final head to succeed and resolve all
   conversations.
7. Merge only with GitHub's native squash merge. The source branch is deleted
   automatically.

Direct, forced, unsigned, missing-DCO, merge-commit, and branch-deletion paths
to `main` are prohibited. No `CODEOWNERS` or approving review is required while
the repository has only one human maintainer.

Never submit real fiscal or personal data, private keys, certificates containing
private material, tokens, or credentials.
